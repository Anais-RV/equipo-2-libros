# 🎨 Frontend Profesional: Primer Impresión Cuenta

**Para:** Data Analysts que creen que "si funciona, da igual cómo se ve"

**Realidad:** NO. La primera impresión es DEFINITIVA.

---

## Lo Mínimo (Tu Gana)

### 1. **Colores Consistentes**
- Elige 3 colores max
- Úsalos en TODOS lados

### 2. **Espaciado Regular**
- Múltiplos de 8px
- Botones: padding 10-15px
- Entre elementos: 16-24px

### 3. **Tipografía Simple**
- 1 font (Roboto, Open Sans)
- Tamaños claros: 12px, 14px, 18px

### 4. **Inputs Claros**
- Borde: 1px gris suave
- Padding: 10px
- Focus: borde color principal

### 5. **Botones Profesionales**
- Relleno con color principal
- Texto blanco
- Padding: 12px 24px
- Bordes redondeados: 4px

---

## BEM: Nomenclatura Profesional

```css
.auth-form { }              /* Block */
.auth-form__input { }       /* Element */
.auth-form__button { }      /* Element */
.auth-form__button--active { } /* Modifier */
```

---

## Lo Que NO Hacer

- ❌ Colores inconsistentes
- ❌ Espaciado aleatorio
- ❌ Inputs sin estilos claros
- ❌ Botones mal diseñados

---

## Lo Que SÍ Hacer

- ✅ Colores limitados y coherentes
- ✅ Espaciado uniforme
- ✅ Inputs con estados (normal, focus)
- ✅ Código limpio con BEM
